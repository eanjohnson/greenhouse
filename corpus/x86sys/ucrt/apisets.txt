# Which guest DLL exports which name. One [section] per DLL the games import
# from; every name in it is a forwarder to ucrtbase.dll, which is where the
# code and the state live. ucrtbase.def is generated from the union, so a name
# listed here must exist in ucrt.c (or in the msvcrt.c it includes).
#
# The names the Half-Life 1 binaries actually import are marked with no
# comment; a few unimported siblings are listed as well, because a forwarder
# costs nothing and the next MSVC-2015 title would otherwise need a deploy to
# add one. `name=symbol` gives the internal symbol when it cannot be spelled
# in C (the two std:: throw helpers).
#
# Membership follows the real UCRT: the mem*/str-search family belongs to
# vcruntime140, not to the string api set.
